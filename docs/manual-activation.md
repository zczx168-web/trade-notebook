## 每次开通

客户也可以在会员中心自行领取 7 天免费试用，无需付款或由你签发。试用开放全部会员功能，每个浏览器正常使用时限领一次，到期不删除交易记录，也不自动扣费。付费开通按下述步骤进行，付费有效期独立计算，不叠加剩余试用时间。试用为本地记录，清除浏览器数据可绕过领取限制。

1. 客户在网站会员中心选择对应收款码，付款后发送付款凭证、会员类型和网站显示的完整设备编号（`TN-` 开头）。请客户在实际使用网站的浏览器中复制编号。
2. 在这台电脑双击项目目录中的 `会员开通工具.cmd`，会在浏览器打开仅本机可访问的管理页面。工具需要已安装的 Node.js。
3. 填写客户设备编号、会员类型、微信实际交易单号。核对收款金额后，勾选已确认到账，再点击签发按钮。
4. 点击复制客户消息，发给客户；也可以下载激活文件后发送。不要把本机管理页面地址发给客户。
5. 客户打开网站“会员中心 → 激活会员”，粘贴完整激活码后点击“验证并激活”，或导入收到的激活 TXT 文件。成功后个人盈亏图表、错误分析和完整复盘报告立即可用，刷新仍保留。

这里不会自动给客户发送微信消息，你仍需手动发送生成的消息或文件。付款、打开二维码和联系客服都不会直接开通会员。测试使用独立测试密钥，没有为真实客户签发生产会员。

## 续费与补发

- 月卡有效期从签发时开始，建议核账后及时签发并发送。续费使用同一设备编号和新的真实交易单号，从当前时间与原到期时间中较晚者顺延 30 天。
- 相同交易单号、设备和会员类型重复提交，返回原激活码，不重复延长有效期。一个交易单号不能用于多个设备或会员类型。
- 客户丢失激活码且设备编号不变，可在工具最近 100 条签发记录中查看并重新复制；更早记录保存在本机完整记录文件内。
- 永久会员不能被月卡降级。已是永久会员的设备需要补发时，复制历史永久激活码。
- 激活码绑定浏览器中的随机设备编号。换电脑、换浏览器、使用无痕窗口或清理网站数据，都可能变成新设备，旧码不能直接激活。当前工具没有跨设备补发或迁移操作；请保留客户原设备编号和激活码，并与客户先确认处理安排。不要编造新的微信交易单号绕过重复校验。
- 当前没有在线撤销功能，退款不能自动停用已发放的离线激活码。

## 本机资料备份

此电脑的资料目录为 `C:/Users/z1384/AppData/Local/TradeNotebookIssuer/`，一般路径为 `%LOCALAPPDATA%/TradeNotebookIssuer/`。

- `issuer.private.pem`：唯一签发私钥。务必离线备份，不能发送给客户、上传 GitHub 或公开。丢失后无法继续签发与当前网站公钥匹配的激活码。
- `issuer-state.json`：真实交易单号、设备编号、有效期和激活码记录。首次签发后生成，应与私钥一起定期备份。
- `issuer-runtime.json`：本机运行信息及启动凭据，无需迁移或公开。

网站仅发布 `site/`，其中 `license-key.js` 是公开验签公钥，可以公开；它不是签发私钥。程序代码可从 GitHub 恢复，私钥和客户签发记录只能从你自己的备份恢复。

备份或迁移前先关闭本机签发服务，避免漏掉刚写入的记录。在新电脑安装 Node.js、恢复原私钥和完整记录到上述资料目录后再启动工具，不要先生成一套新密钥。恢复后应检查私钥与网站公钥匹配，工具也会自动检查并在不匹配时停止。

若异常退出后提示签发锁占用，在任务管理器中确认该会员开通服务已经停止，再删除资料目录中的 `issue.lock` 文件并重新启动。服务正在运行时不要删除锁文件。不要删除私钥和签发记录来解决启动问题。

## 权限边界

激活码使用数字签名，网站会拒绝被篡改、已过期或设备不匹配的码，但复盘功能和权限判断都在客户浏览器运行。技术用户修改网页代码、设备编号或系统时间仍可绕过限制。此方案用于人工开通流程，不等同于服务端付费权限系统，也没有在线账号、跨设备同步或远程撤销能力。

客户账本保存在客户浏览器内，不保存在本机签发工具中；请客户通过网站备份功能保存交易数据。
